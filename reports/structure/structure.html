AI Workout Coach
Project structure · v0.1

One folder per job, one direction for the data.

Raw datasets go in, are never modified, and flow one way through cleaning → models → results. Code lives in one Python package (awc), every path comes from one config file, and the README logs each finished step.

2How data flows

data/raw/MM-Fit · EC3D · our recordings, as downloaded
↓ features/ + bigdata/ (Spark)
data/interim/streams synced on the 30 fps clock, skeletons normalized
↓ features/windows, reps
data/processed/3 s windows (Model 1), one tensor per rep (Models 2, 3)
↓ models/ + training/ (PyTorch)
models/ · experiments/checkpoints, configs, metrics of every run
↓ evaluation/
reports/benchmarks answering RQ1–RQ4

Live mode: streaming/ (Kafka) feeds the trained models and coach/ speaks the result.

4Rules we follow

Raw data is read-onlyEvery result can be rebuilt from the original files.
One source of pathsAll code imports its paths from config.py.
Data stays out of gitOnly code, docs and results are versioned; data/README.md says how to download.
Tested and loggedTests check the datasets; the README logs every finished step.
